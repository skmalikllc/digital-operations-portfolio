# Digital Operations — earlier work

**Project type:** Sanitized engagement record — earlier and secondary work
**Evidence sources:** completed Fiverr orders, public client reviews, published Fiverr portfolio projects, historical account audit

This is the earlier half of my freelance history: e-commerce operations,
real-estate support, e-learning setup, analysis and document work. It is real,
it is reviewed, and it is where a lot of the practical Workspace and
data-handling habit came from.

It is kept separate on purpose. My current work is automation, integration and
data migration — see **[automation-portfolio](https://github.com/skmalikllc/automation-portfolio)**
for that. This repository exists so the earlier record is available without
crowding out the current one.

---

## E-commerce operations

Product listing and catalogue work across **Amazon, eBay, Etsy and Shopify** —
product upload, listing creation, product image editing and e-commerce SEO.
Delivered repeatedly through Fiverr at 5 stars, and published as portfolio
projects there.

## Real-estate and property support

Virtual assistance for real-estate and property businesses — the administrative
and document side rather than the transactional one.

## E-learning and platform setup

Course content organisation for an e-learning business (November 2024): a
structured folder system plus a master navigation document, so course material
could be found rather than searched for. Recorded project value $100–$200.

## Analysis and document work

- **Staffing cost analysis** for a California school district: comparing
  contracted versus direct-hire paraprofessional staffing costs from spreadsheet
  data.
- **SOP restructuring**: converting an analysis toolkit SOP into a professionally
  formatted Word document, generated with Node.js rather than assembled by hand,
  through several rounds of client feedback.
- **Offline dashboard**: converting an Excel workbook into a fully self-contained
  HTML dashboard for use on a PC with no internet access.

## Why this is a separate repository

Some of this work is data entry and some of it is design, and neither is what I
want a client evaluating an automation project to judge me on. But it happened,
it was delivered, and leaving it off entirely would be its own kind of
misrepresentation.
